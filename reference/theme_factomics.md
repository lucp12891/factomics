# The factomics ggplot2 theme and colour palette

The factomics ggplot2 theme and colour palette

## Usage

``` r
theme_factomics(base_size = 11)

factomics_palette(n)
```

## Arguments

- base_size:

  Base font size.

- n:

  Number of colours.

## Value

`theme_factomics()` returns a ggplot2 theme; `factomics_palette()`
returns a character vector of colours.
